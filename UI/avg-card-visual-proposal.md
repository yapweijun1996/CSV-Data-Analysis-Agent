# Avg card: mobile visual changes

This is an illustrative proposal; its displayed values are placeholders, not HDB results.

- Keep **Avg Resale Price by Town** and the existing **Unverified** trust badge together in the card header; retain the blue brand for the selected control and chart marks.
- Replace the compressed 27-category combo chart with a sorted, horizontal **Top 8** bar chart. Put town labels on the left and readable average-price values on the right; avoid angled labels and the crowded secondary transaction axis.
- Add a clear **Chart / Table · 27 rows** switch. Table mode exposes every town and its value, with a sticky header and vertical scrolling on mobile. Keep chart type, Top 8/All, and Export controls separate and at least 44 px high.
- In **All** chart mode, preserve legibility: use horizontal bars in a vertically scrollable plot with a fixed readable row height and pinned town/value labels, or page through a bounded set of categories. Never shrink text or cram all 27 categories into one viewport. Keep the table as the direct all-row view.
- Preserve the description and export action, but let the chart/table content use the available card width and scroll vertically rather than forcing desktop two-column layout onto mobile.
